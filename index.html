Projects

Value Buy Smartphone Data Analysis

This project explores the existing smartphone products with price range from 1 to 5 million IDR to create a new smartphone product with similar features. The data was scraped from Tokopedia, a leading e-commerce in Indonesia. Please click for more details from data extraction, cleaning, to visualization on Tableau.

Predict House Price

This project utilizes SOTA regression model to estimate the house price based on given house information from a Kaggle Dataset. You can also find some statistical studies that lead to feature transformation decisions. The final model is deployed on HuggingFace, so check it out!

CreditGuide

This project is about developing a predictive model to classify bank clients as default or non-default based on their payment behaviors on their credit obligations. Please try the final model on HuggingFace!
